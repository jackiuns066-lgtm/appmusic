# بستهٔ انتشار در فروشگاه (Cafe Bazaar / Google Play)

این پوشه همهٔ دارایی‌هایی را دارد که برای ثبت و انتشار اپ لازم است.

| فایل | مشخصات | الزام فروشگاه |
|---|---|---|
| `icon-512.png` | ۵۱۲×۵۱۲ | کافه‌بازار: حداقل ۵۱۲px، حداکثر ۳۰۰۰px، حجم ≤ ۳MB |
| `feature-graphic-1024x500.png` | ۱۰۲۴×۵۰۰ | کافه‌بازار («تصویر سرصفحه»): حداقل ۷۲۰×۲۸۸، نسبت ۵:۲، PNG، حجم ≤ ۱MB |
| `screenshots/01…06-*.png` | ۱۰۸۰×۱۹۲۰ | کافه‌بازار حداقل ۱ اسکرین‌شات (۵–۶ توصیه می‌شود، حداکثر ۱۲، هرکدام ≤ ۱MB) |
| `generate_store_kit.py` | اسکریپت تولید همهٔ موارد بالا | بعد از هر تغییر رابط کاربری، یک‌بار اجرا کنید |

اجرای دوبارهٔ تولید دارایی‌ها:

```bash
PYTHONPATH=/home/user/.tools python3 store/generate_store_kit.py
```

> نکته: اسکرین‌شات‌ها ماکاپ با کیفیت بالا از صفحه‌های واقعی برنامه‌اند (رنگ‌ها، متن‌ها و چیدمان همان اپ است).
> اگر بازبین فروشگاه اسکرین‌شات «واقعی» خواست، از گوشی خودتان از همین صفحه‌ها عکس بگیرید و
> فایل‌ها را با همین نام‌ها جایگزین کنید.

## مراحل انتشار در کافه‌بازار (پیشخان)

1. ثبت‌نام و ساخت حساب توسعه‌دهنده در [پیشخان بازار](https://pishkhan.cafebazaar.ir) (نیاز به کارت ملی و شبا).
2. «برنامهٔ جدید» → انتخاب دستهٔ **موسیقی و صدا** → آپلود فایل بسته.
   - ساده‌ترین راه: فایل **AAB** که در هر بیلد منتشر می‌شود:
     `…/releases/download/apk-latest/Novo-<کدنسخه>.aab`
     بازار برای AAB یک ابزار «bundle signer» می‌خواهد تا فایل `.bin` بسازید
     (ابزار رسمی: <https://github.com/cafebazaar/bundle-signer>).
   - راه سریع‌تر: همان `Novo-release.apk` (سقف حجم بسته در بازار ۱۵۰ مگابایت است و فایل ما ۱۲ مگابایت).
3. آپلود آیکون، تصویر سرصفحه و اسکرین‌شات‌ها از همین پوشه.
4. عنوان، توضیح کوتاه و توضیح کامل: در `play_store_listing.json` آماده است (بخش‌های `listing` فارسی و `listing_en` انگلیسی).
5. اطلاعات پشتیبانی (ایمیل/وب‌سایت: `webnovo.ir`) و ارسال برای بررسی.

## چرا این کار خطای «بستهٔ متناقض» را برای کاربران تمام می‌کند؟

شناسهٔ عمومی برنامه **`ir.webnovo.novo`** است؛ هیچ اپ دیگری این شناسه را ندارد. اگر اپ در فروشگاه
منتشر شود، نصب و همهٔ به‌روزرسانی‌های بعدی توسط خود فروشگاه انجام می‌شود، پس کاربر هرگز پیام
«App not installed as package conflicts with an existing package» نمی‌بیند.

## کانال‌ها (خلاصهٔ فنی)

| کانال | شناسهٔ بسته | خروجی |
|---|---|---|
| عمومی (فروشگاه) | `ir.webnovo.novo` | `Novo-release.apk` · `Novo-<کدنسخه>.aab` |
| قدیمی/آزمایشی | `com.aistudio.avamusic.player.canary` | `Novo-canary.apk` |

هر دو کانال با یک کلید امضا می‌شوند و `versionCode` هر بیلد = `10100 + شمارهٔ اجرای GitHub Actions`.
