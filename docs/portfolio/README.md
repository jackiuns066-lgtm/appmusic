# افزودن «نوو» به سایت نمونه‌کارها (وب‌نوو پورتفولیو)

مخزن سایت شما (`rsabzi/bot-company`) از این نشست قابل دسترسی نیست — کانکشن گیت‌هاب این محیط فقط
روی مخزن `appmusic` باز است. پس دو راه دارید:

## راه ۱ — کپی‌پیست (۳ دقیقه، همین حالا)

1. فایل **`novo-portfolio-fa.html`** را باز کنید و کل بلوک `<section>` را کپی کنید.
2. در صفحهٔ نمونه‌کارهای سایت، همان‌جا که بقیهٔ کارت‌ها هستند، پیست کنید.
3. تصاویر: پوشهٔ `store/screenshots/` را در سایت خودتان هم بگذارید (مثلاً
   `public/images/novo/` ) و مسیر `src="store/screenshots/..."` را به مسیر خودتان تغییر دهید.
   تصویر شاخص پیشنهادی: `03-home-widget.png` (ویجت، جذاب‌ترین تصویر اپ).
   اگر فقط یک عکس می‌خواهید: `docs/apk-download-qr.png` یا `store/icon-512.png` هم گزینه‌اند.
4. اگر سایت شما داده‌محور است (آرایهٔ JSON/JS)، به‌جای HTML از **`novo-portfolio.json`** استفاده کنید؛
   همهٔ فیلدها (فارسی و انگلیسی) داخلش آماده است.

> نکتهٔ طراحی: کارت با پالت خود اپ (مشکی AMOLED + طلایی) نوشته شده و RTL است؛ اگر سایت روشن است،
> فقط `background` و `color` بخش `<section>` را با تم سایت هماهنگ کنید.

## راه ۲ — من خودم PR بزنم (اگر دسترسی بدهید)

1. در Arena، اتصال GitHub را طوری وصل کنید که مخزن `rsabzi/bot-company` هم در فهرست باشد
   (نصب GitHub App روی آن مخزن یا افزودن مخزن به دسترسی‌های موجود).
2. بعد فقط بنویسید «دسترسی دادم» — من:
   - مخزن را می‌خوانم و ساختار بخش نمونه‌کارها را پیدا می‌کنم،
   - تصاویر را در جای درست کپی می‌کنم،
   - متن را با همان کامپوننت/قالب سایت شما (React/Next/HTML/هرچه باشد) اضافه می‌کنم،
   - یک شاخهٔ جدا می‌سازم و **Pull Request** می‌دهم تا خودتان بازبینی و merge کنید.

## چه چیزی در متن آمده (لحن و محتوا)

- **لحن انسانی**: از «چرا ساختیم» و «چه چیزی سخت بود» شروع می‌شود، نه از فهرست امکانات خشک.
- **واقعی و قابل ردیابی**: هر عدد و هر ادعا از خودِ پروژه می‌آید
  (حجم ~۱۳ مگابایت، اندروید ۷ تا ۱۶، شش کنترل ویجت، اکولایزر ۵ باندی، شناسهٔ `ir.webnovo.novo`،
  امضای ثابت و کد نسخهٔ خودافزا، بدون مجوز اینترنت، بدون تبلیغ و خرید درون‌برنامه‌ای).
- **بدون بزرگ‌نمایی**: عدد نصب یا امتیاز جعلی ندارد؛ وضعیت کافه‌بازار «در حال بررسی» ذکر شده است.
- **دو روایت**: نسخهٔ فارسی برای سایت خودتان، نسخهٔ انگلیسی در JSON برای صفحهٔ دوزبانه یا لینکدین.
